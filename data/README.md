# Data

The competition files are not included in this repo. Download them from the Kaggle competition page (**Classical Music Meets Classical ML**, Data tab) and put them in this folder:

```
data/
├── train.csv
├── test.csv
├── sample_submission.csv
├── account.csv
├── subscriptions.csv
├── tickets_all.csv
├── concerts.csv
├── concerts_2014-15.csv
└── zipcodes.csv
```

The files are not redistributed here. The tests do not need them: `tests/synthetic.py` writes a small synthetic copy with the same schema.
